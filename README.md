## 📖 Analytical Framework

```yaml
Step 0: Timeliness Check
  - Determine latest available reports (annual / quarterly / semi-annual)
  - Web-search latest market land price benchmarks

Step 1: Asset Cost Breakdown
  - Land cost + construction cost, sourced to exact prospectus page numbers
  - Land Discount Ratio = book land price ÷ market land auction price

Step 2: DuPont ROI Decomposition
  - ROI = EBITDA ÷ Asset Cost
  - ROI = EBITDA Margin (ops) × Asset Turnover (cost leverage)
  - Same ROI can come from entirely different paths

Step 3: Cash Flow Tracing
  - Net Profit → + Depreciation → − CapEx = Distributable Income
  - Depreciation Rate × Asset Cost → quantify "where the extra cash comes from"

Step 4: Geographic Layering
  - Shanghai (same-city, primary) → National (cross-city, secondary)
  - Real estate is local — never ignore geography

Step 5: Synthesis
  - Financial: capital structure, operating leverage, valuation
  - Operational: economies of scale, revenue quality, cost efficiency
  - Economic: Ricardian Rent, Principal-Agent Theory, Economies of Scale
```

## ❓ FAQ

<details>
<summary><b>Q: How reliable is the data?</b></summary>
Every figure is sourced to exact page numbers in annual reports, prospectuses, or exchange filings. The skill performs live web searches for the latest data — nothing is hardcoded.
</details>

<details>
<summary><b>Q: Why EBITDA instead of Net Profit?</b></summary>
Different REITs have vastly different depreciation policies (annual rates range from 1.35% to 4.18% of asset cost). Using EBITDA (before depreciation) enables fair cross-comparison.
</details>

<details>
<summary><b>Q: How is the Land Discount Ratio calculated?</b></summary>
Ratio = Book Land Price ÷ Market Land Auction Price (same-area commercial residential). Market benchmarks come from 2024-2025 public land auction results (e.g., Yangpu R4 plot 6,600 CNY/㎡, Baoshan residential 25,000-37,000 CNY/㎡). Updated each analysis run via web search.
</details>

<details>
<summary><b>Q: Can I use this for investment decisions?</b></summary>
This project provides analytical frameworks and methodology — not investment advice. Always verify data and consult a licensed professional before making investment decisions.
</details>

<details>
<summary><b>Q: Is this only for Claude Code?</b></summary>
No. `SKILL.md` is pure Markdown — it works with any AI agent that supports Skill/knowledge injection. See the compatibility table above.
</details>
