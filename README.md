## 📖 核心分析框架

### 1. ROI 杜邦分解

```
ROI = EBITDA ÷ 资产成本
    = (EBITDA ÷ 营收) × (营收 ÷ 资产成本)
    = EBITDA率(运营效率) × 资产周转率(成本杠杆)
```

**同一个ROI，路径可能完全不同** — 有的靠运营（高利润率），有的靠成本（高周转率）。

### 2. 土地折价量化

```
折价率 = 项目账面地价 ÷ 同区域商品住宅市场楼面价
```

| 拿地方式 | 折价率 | 代表REIT | 解读 |
|------|:---:|------|------|
| 划拨地 | 0.4-2.2折 | 华夏北京 | 几乎白送，ROI虚高不可简单对标 |
| R4协议地 | 0.5-1.7折 | 城投宽庭 | 地价仅为商品住宅1/60~1/200 |
| 招拍挂租赁 | 1.5-2.4折 | 华润有巢 | 租赁用地有一定折让 |

### 3. 现金流追溯

```
可供分配金额 = 净利润 + 折旧摊销 - 资本性支出 + 其他调整
多出来的钱   = 折旧摊销 - 实际维修支出
```

建筑物使用50-70年，折旧账上摊20-30年 → 折旧远大于实际维护 → 差额就是"多出来的现金"。

### 4. 四层分析架构

```yaml
第一层: 品牌主体层 — 7家公司全指标对照 + 四维排名
第二层: 项目层 — 全部底层项目逐一定量对比
第三层: 土地折价 — 统一基准vs商品住宅市场价
第四层: 综合论述 — 金融+经营+经济学视角
```

## ❓ 你可能想问

<details>
<summary><b>Q: 数据靠谱吗？</b></summary>
每个数字标注了精确来源：年报页码、招股书页码、交易所公告链接。Skill运行时联网搜索最新数据，不固化静态数字。
</details>

<details>
<summary><b>Q: 为什么用EBITDA不是净利润？</b></summary>
有的REITs是重资产（有折旧），有的没有→净利润口径不一致。统一用EBITDA（都不考虑折旧）才能公平对比。详见SKILL.md。
</details>

<details>
<summary><b>Q: 折价率怎么算的？</b></summary>
折价率=项目账面地价÷同区域商品住宅招拍挂楼面价。市场地价基准通过联网搜索获取（如杨浦R4地块6,600元/㎡、宝山住宅25,000-37,000元/㎡），每次分析更新。
</details>

<details>
<summary><b>Q: 能不能直接用于投资决策？</b></summary>
提供分析框架和方法论，不构成投资建议。数据请自行核实，投资前咨询专业顾问。
</details>
