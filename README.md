## 🧠 它教你的不只是一份报告，是一套思维

这套方法论拆成 **5 种可迁移的能力**：

| 能力 | 你会学到 |
|------|------|
| 🔬 **拆解力** | 把一份300页的年报拆成8个定量数据点，知道去哪里找、看哪一行 |
| 📐 **量化力** | 用"土地折价率"把"这块地便宜"变成"相当于市场价的1.8折" |
| 💰 **归因力** | ROI低是因为资产贵还是运营差？杜邦分解一招分清 |
| 🌍 **分层力** | 不动产有地域属性——同城首选，全国参照 |
| 🎓 **学术力** | 地租理论×委托代理×规模经济——你的报告能上学术期刊 |

## 📖 完整分析框架（四层）

```yaml
第一层 品牌主体层:
  - 8家公司11项指标全对照
  - 四维排名：EBITDA率→周转率→资产规模→ROI
  - 地域分层：上海同城（首选）→ 全国异地（参照）

第二层 股东分公司层:
  - 睿华/顾华/华行 各自杜邦分解
  - 每分公司旗下项目逐一拆解+对标最接近的上市REIT

第三层 项目层:
  - 全23标的统一排名（17张大华+8张REITs）
  - 每项目含：ROI+杜邦+坪效+出租率+单房月均+折价率+归因标签

第四层 综合论述:
  - 金融层面：资本结构+经营杠杆+EV/EBITDA估值
  - 经营层面：规模经济+范围经济+收入质量+成本改善
  - 经济学视角：地租理论(Ricardo)+委托代理(Jensen)+规模经济
  - 战略建议：短中长期三阶段
```

## 🔥 硬核数据预览

### ROI 杜邦分解（同一个ROI，不同的故事）

| | 🟠 大华·联2锦秋路 | 🔷 城投·江湾 |
|------|:---:|:---:|
| ROI | 3.16% | 3.15% |
| EBITDA率（运营） | **82.7%** 🏆 | 45.9% |
| 周转率（成本） | 3.82% | **6.99%** 🏆 |
| **路径** | 运营驱动的极致效率 | 成本驱动的极致杠杆 |

> 💡 **核心洞察**：ROI一模一样，但一个靠运营（每收100元剩83元利润），一个靠成本（R4地价仅为商品住宅的0.5-1.7%）。

### 土地折价率梯度（谁的地最便宜？）

| 拿地方式 | 相当于市场价 | 代表 | 便宜了多少 |
|------|:---:|------|:---:|
| 划拨地 | 0.4-2.2折 | 华夏北京 | 几乎白送 |
| R4协议地 | 0.5-1.7折 | 城投宽庭 | 仅为商品住宅1/60~1/200 |
| 开发商自有地 | 1.8-3.9折 | 大华享寓 | 市场价的2-4折 |
| 招拍挂租赁 | 1.5-2.4折 | 华润有巢 | 市场价的2折 |

## ❓ 你可能想问

<details>
<summary><b>Q: 数据靠谱吗？</b></summary>
每个数字标注了精确来源：年报页码、招股书页码、交易所公告链接。不瞎编，不估计。
</details>

<details>
<summary><b>Q: 为什么用EBITDA不是净利润？</b></summary>
大华（轻资产）无折旧，REITs（重资产）有折旧→净利润口径不一致。统一用EBITDA（都不考虑折旧）才能公平对比。详见SKILL.md §1.2。
</details>

<details>
<summary><b>Q: 能不能直接用于投资决策？</b></summary>
提供方法和框架，不构成投资建议。数据请自行核实，投资前咨询专业顾问。
</details>

<details>
<summary><b>Q: 怎么更新数据？</b></summary>
Skill内置时间敏感逻辑——运行时会自动判断当前可获取的最新报告（年报/季报/半年报），联网搜索最新数据。不固化任何时点的静态数字。
</details>
